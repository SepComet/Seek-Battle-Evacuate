# 核心循环

> 状态：草案

## 完整循环

`局外 UI 整备 → 进入固定地牢 → 搜索物资与接触敌人 → 回合制战斗 → 继续探索 → 成功撤离、死亡或超时 → 结算后返回局外 UI`

## 出发前

玩家在局外 UI 中完成进入地图前的操作：

- 配置出战角色。
- 配置携带进入地图的物品。
- 在战备功能中选择本局难度。
- 允许玩家输入本局使用的随机数。

## 进入地图后

- 地图的房间和连接结构固定。
- 使用玩家输入的随机数初始化本局随机生成器。
- 每次进入地图时，根据随机数与难度确定性构建物资点和怪物分布。
- 开始探索前，一次性生成并保存所有物资点中的物品数量、稀有度和具体物品；单局过程中不会重新生成物资点内容。
- 根据本局随机数，从预设撤离点中决定一个开放点位。
- 开局生成完成后，敌人 AI、逃跑判定和敌人掉落等运行时随机继续沿用本局随机生成器。
- 进入地图后，在游戏 UI 上显示本局使用的随机数。

## 搜索与遭遇

- 玩家通过 WASD 在房间之间移动并搜索物资。
- 敌人具有警惕值；警惕值满后会追击玩家。
- 玩家与敌人接触后进入战斗。
- 玩家在敌人警惕值未满时主动进入战斗，可以获得第一轮的先制优势。

## 单局计时

- 单局时间上限为 25 分钟。
- 正常探索和打开背包时，单局计时继续。
- 进入回合制战斗后，单局计时暂停。
- 打开菜单时进入暂停页面，单局计时暂停。
- 达到 25 分钟上限时仍未成功撤离，直接判定撤离失败，只保留保险箱中的物品。

## 战斗结束后

- 战斗胜利后，触发战斗的地图敌人消失。
- 该敌人有概率在地图上掉落部分物品。
- 玩家回到进入战斗前所在的位置。
- 未在战斗中阵亡的玩家角色将当前 HP 和 MP 原样带回探索。
- 只要战斗不是以全员阵亡结束，所有在本场战斗中阵亡的玩家角色都以 1 点 HP 和 1 点 MP 返回探索。
- 战斗中的状态不会带回探索。
- 其他地图敌人的警惕和追击状态保持不变。

## 撤离或死亡

- 本局开放的撤离点在时限内可以随时使用。
- 单局计时达到 20 分钟时，通过小地图 UI 标记本局开放的撤离点并提醒玩家。
- 与本局开放的撤离点交互后立即成功撤离。
- 成功撤离时，背包内的全部内容进入主仓库。
- 玩家死亡时，只保留保险箱内的内容。

## 回到局外后

局外以完整 UI 形式存在。成功撤离的背包内容进入主仓库；死亡结算只保留保险箱内容。

## 玩家最主要的风险选择

- 是否在敌人警惕值未满时主动接敌，以换取先制优势。
- 获得物资后继续探索，还是前往本局开放的撤离点。

## 还没决定的问题

暂无。敌人掉落物品的具体概率和内容在物品设计中确定。
