# SBE 简版游戏设计

> 面向单人开发的第一版可玩原型，只记录会直接影响当前开发的设计。

## 文档

| 顺序 | 文档 | 用途 |
| --- | --- | --- |
| 1 | [游戏概述](01_GameOverview.md) | 确定游戏要提供什么体验 |
| 2 | [核心循环](02_CoreLoop.md) | 串起整备、搜索、战斗和撤离 |
| 3 | [单局探索](03_RunExploration.md) | 定义一局中玩家如何行动 |
| 4 | [回合制战斗](04_TurnBasedCombat.md) | 定义最小战斗规则 |
| 5 | [物品与成长](05_LootAndProgression.md) | 定义战利品的获得、损失和用途 |
| 6 | [原型范围](06_PrototypeScope.md) | 控制内容量并判断原型是否完成 |

## 使用原则

- 只填写下一阶段开发必须知道的答案。
- 暂时没有答案的项目保留“待填写”，不为未来扩展提前设计。
- 新机制只有在现有文档放不下时，才新增独立文档。
