# 原型范围

> 状态：草案

## 这版原型要验证什么

验证固定瓦片地牢中的搜索、警惕追击、多对多回合战斗、随机撤离和物品结算能否形成一轮可重复游玩的简单搜打撤流程。

## 最短完整游玩流程

`局外仓库与战备 → 配置队伍、随机数和难度 → 进入固定地图 → 搜索物资 → 主动接敌或被敌人追击 → 完成回合制战斗 → 成功撤离、逃跑后继续探索或单局失败 → 返回局外 UI 并保存结果`

## 最小内容量

| 内容 | 数量 |
| --- | --- |
| 地图 | 1 张 |
| 固定房间结构 | 1 套 |
| 预设撤离点 | 由地图配置，不在本文档固定数量 |
| 玩家角色 | 4 个 |
| 每名玩家角色的技能 | 1 个 |
| 难度 | 3 档 |
| 物资点类型 | 5 种 |
| 敌人类型与队伍预设 | 由配表决定，不在本文档固定数量 |
| 战利品、武器、防具和消耗品 | 由配表决定，不在本文档固定数量 |

## 必须完成

- [ ] 新存档直接拥有全部 4 名玩家角色，主仓库为空，战备最少选择 1 人、最多选择 4 人出战。
- [ ] 固定房间结构的瓦片地图与 WASD 移动。
- [ ] 整张地图一次性加载，所有出战角色跟随队长移动。
- [ ] 根据随机数与难度确定性构建物资点和怪物分布。
- [ ] 进入地图时先生成并冻结所有物资点的物品数量和种类，之后继续使用同一个本局随机生成器处理运行时随机。
- [ ] 支持玩家输入随机数、选择 3 档难度，并在局内显示本局随机数。
- [ ] 5 种物资点能够按数量、稀有度权重和具体道具生成内容，并支持长按搜索。
- [ ] 敌人警惕、追击和接触进入战斗。
- [ ] 多对多、速度排序、每轮每个角色行动一次的回合制战斗。
- [ ] 轮到玩家角色时再选择该角色行动。
- [ ] 未满警惕时主动接敌获得第一轮先制优势。
- [ ] 4 名玩家角色各拥有 1 个技能，并支持攻击、技能和概率逃跑。
- [ ] 任何非全员阵亡的战斗结束后，本场阵亡角色都以 1 点 HP 和 1 点 MP 返回探索。
- [ ] 每局随机开放一个预设撤离点。
- [ ] 单局上限为 25 分钟，第 20 分钟通过小地图标记开放撤离点。
- [ ] 成功撤离与死亡的物品结算。
- [ ] 30 格共享背包、5 格保险箱、无容量上限的主仓库，以及武器栏和防具栏。
- [ ] 战斗中无法打开共享背包或保险箱；首版不实现道具专属栏位的实际使用功能。
- [ ] 纯 UI 形式的局外仓库与战备功能。
- [ ] 本地存档保存主仓库内容、角色装备、当前战备配置等局外状态。
- [ ] 进入单局时，根据进入前的局外状态创建仅供本局使用的临时状态。
- [ ] 单局进行过程中只修改临时状态，不写入游戏存档。
- [ ] 单局正常产生结算时，一次性将结算结果写入局外状态，并保存该局的结算数据。
- [ ] 玩家主动退出单局时，按撤离失败进行结算，只保留保险箱内容，并将失败结果写入游戏存档。
- [ ] 不保存进行中的单局状态，也不支持重新启动游戏后继续未结束的单局。

## 明确不做

- 多张地图。
- 随机生成房间结构或房间连接关系。
- 分房间流式加载。
- 局外可移动地图或基地场景。
- 钥匙卡、战斗道具和消耗品效果。
- 战利品出售、消耗和成长系统。
- 复杂伤害公式和复杂敌人 AI。
- 墙体阻挡敌人视野；首版警惕判定允许穿墙。
- 保存或恢复进行中的单局。

## 原型通过条件

- [ ] 玩家可以从局外 UI 进入一局游戏并返回。
- [ ] 能够在固定地图中完成移动、搜索、遭遇和多对多战斗。
- [ ] 相同随机数与难度能够复现相同的物资点和怪物分布。
- [ ] 物资点内容在进入地图时一次性确定，后续 AI、逃跑和掉落的随机调用不会改变已经生成的物资点内容。
- [ ] 3 档难度都能够创建并完成一局游戏。
- [ ] 能够通过本局开放的撤离点成功撤离并将背包内容存入主仓库。
- [ ] 玩家死亡时只保留保险箱内容。
- [ ] 概率逃跑、部分角色阵亡恢复和 2 秒地图保护能够按战斗文档运行。
- [ ] 2 秒保护期间敌人不会追击；保护结束时仍与敌人重叠则允许立即再次进入战斗。
- [ ] 退出并重新打开游戏后，局外主仓库、角色装备和战备配置能够从本地存档恢复。
- [ ] 已结束单局的结算数据能够写入本地存档并在重新打开游戏后读取。
- [ ] 重新打开游戏时不会恢复尚未结束的单局。
- [ ] 单局中主动退出时能够按撤离失败结算，保存保险箱内容和本局失败记录。
- [ ] 单局发生异常关闭时，临时状态会被丢弃，重新进入游戏后恢复进入该局之前的局外状态。
- [ ] 异常关闭的未结算单局不会修改局外存档，也不会生成结算记录。

## 还没决定的问题

暂无。整个单局过程使用临时状态；成功撤离、失败、超时和主动退出都会产生结算并写入游戏存档，异常关闭则回退到进入单局之前的局外状态。

撤离点数量由地图资产决定；敌人、队伍预设和物品数量由后续配表决定，不作为本文档的待决问题。
