# 物品与成长

> 状态：草案

## 物品分成哪些类型

- 战利品。
- 装备。
- 消耗品。

物品稀有度分为 5 档：

- 白色。
- 绿色。
- 蓝色。
- 金色。
- 红色。

## 战利品从哪里获得

- 物资点根据“物资点类型 × 难度”配置刷新道具数量和各稀有度的刷新权重。
- 生成物资点内容时，先随机道具数量，再逐个随机稀有度，最后从对应稀有度的道具集合中随机具体道具。
- 物资点内的物品通过长按搜索逐件掉落到地图，再由玩家靠近并交互拾取。
- 战斗胜利后，敌人有概率在地图上掉落物品。
- 敌人使用独立掉落表，不与物资点共用配置数据；掉落表的数据结构和生成步骤与物资点一致。

## 背包有什么限制

- 全队共用一个背包。
- 背包采用固定格子容量，共 30 格。
- 物品允许堆叠，每种物品单独配置自己的堆叠上限。
- 背包已满时显示“背包已满”提示，并拒绝拾取该物品。

## 保险箱

- 全队共用一个保险箱。
- 保险箱与背包相互独立，容量为 5 个格子。
- 所有物品类型都允许放入保险箱。
- 非战斗状态下，物品可以随时移入或移出保险箱。
- 战斗中不能打开共享背包或保险箱，也不能调整保险箱内容。

## 物品如何使用

- 首版只实现配置携带物品进入地图的能力，背包中普通携带的物品本身不产生局内效果。
- 首版不实现钥匙卡、战斗道具等特殊用途。
- 消耗品类型保留，但首版不实现具体消耗效果。
- 后续实现战斗道具时，只有在战斗开始前装备到道具专属栏位的道具才能在战斗中使用；战斗中不能从背包临时选择道具。
- 每名角色只设置武器栏和防具栏。
- 装备属于物品；未穿戴时可以存放在背包、保险箱或主仓库中。
- 装备穿戴在角色自己的对应装备栏中，穿戴后不占用共享背包格子，并影响角色属性。
- 装备可以影响角色的生命值（HP）、魔力值（MP）、攻击力（ATK）和魔力（MAT）。
- 装备对 HP 和 MP 的影响只修改对应的上限值，不直接增加或恢复当前值。
- 换装或卸下装备后，如果当前 HP 或 MP 高于新的上限值，则立即将当前值钳制到对应的新上限值。
- 在地图中拾取装备时，如果存在空缺的对应装备栏，按照角色加入队伍的顺序查找，并优先将装备穿入最先找到的空装备栏。
- 如果没有可用的对应装备栏，拾取的装备进入共享背包。
- 如果没有可用装备栏且共享背包已满，则拒绝拾取并显示“背包已满”提示。
- 手动更换装备时，新装备与旧装备直接交换位置：新装备进入角色装备栏，旧装备进入新装备原本所在的格子。
- 换装不需要额外的空背包格，因此背包已满时仍然允许更换装备。

## 哪些东西能带出

- 成功撤离时，背包中的全部内容进入局外主仓库。
- 成功撤离时，保险箱中的全部内容也进入局外主仓库。
- 成功撤离时，角色装备栏中的装备保持穿戴，不进入主仓库。

## 死亡会失去什么

- 本局游戏失败或超时撤离失败时，只保留保险箱中的内容。
- 保险箱之外的背包物品和其他随身物品全部损失，不会进入主仓库。
- 角色装备栏中的装备不属于保险箱；本局游戏失败时，已穿戴装备也会丢失。
- 保险箱内的物品不会丢失，返回主界面后进入主仓库。

## 非全员阵亡后的装备处理

- 只要战斗不是以全员阵亡结束，本局游戏就不会因本场战斗中的角色阵亡而失败。
- 成功逃跑角色身上的装备保持穿戴。
- 战斗中阵亡但随队返回探索的角色，其装备也保持穿戴。
- 阵亡只是战斗中的状态；返回探索后，这些角色的 HP 和 MP 都设置为 1，可以正常参加下一场战斗。

## 局外如何存放物品

- 局外通过 UI 提供主仓库。
- 新存档的主仓库为空。
- 主仓库没有容量上限。
- 成功撤离后，背包与保险箱中的物品进入主仓库。
- 本局游戏失败后，只有保险箱中的物品进入主仓库。

## 带出的东西有什么用途

- 首版中，战利品只用于收藏。
- 首版不实现出售、消耗或成长用途。

## 失败后如何保证还能继续游戏

保险箱为本局游戏失败后的最低保留手段。玩家可以在非战斗状态下随时将希望保留的物品放入保险箱；失败后，这些物品会进入无容量上限的主仓库。

## 原型验收

- [ ] 全队共用一个固定格子背包和一个独立的 5 格保险箱。
- [ ] 共享背包固定为 30 格。
- [ ] 物品能够按照各自的堆叠上限堆叠。
- [ ] 背包已满时拒绝拾取，并显示“背包已满”提示。
- [ ] 所有物品都能在非战斗状态下随时移入或移出保险箱，战斗中无法打开背包或保险箱。
- [ ] 每名角色拥有武器栏和防具栏，穿戴装备不占用共享背包格子，并能影响 HP、MP、ATK 和 MAT。
- [ ] 装备只修改 HP/MP 上限；换装后当前值超过新上限时能够正确钳制。
- [ ] 拾取装备时按照入队顺序优先填入空缺的对应装备栏，否则进入共享背包。
- [ ] 手动换装时新旧装备直接交换位置，背包已满时也能完成更换。
- [ ] 成功撤离后，背包中的全部内容能够进入主仓库。
- [ ] 成功撤离后，保险箱中的全部内容能够进入主仓库。
- [ ] 玩家死亡后，只有保险箱中的内容得到保留。
- [ ] 死亡结算不会将保险箱外的随身内容存入主仓库。
- [ ] 主仓库不限制容量。
- [ ] 成功撤离后已穿戴装备保持穿戴；部分角色逃跑时，所有随队返回角色也保留已穿戴装备。
- [ ] 任何非全员阵亡的战斗结束后，阵亡角色以 1 点 HP 和 1 点 MP 返回并保留装备。

## 还没决定的问题

暂无。装备的具体属性数值留到后续配表阶段确定。
