# 单局探索

> 状态：草案

## 一局如何开始

- 加载唯一一张固定结构的瓦片地图。
- 玩家输入本局随机数，并在战备时选择难度。
- 使用玩家输入的随机数初始化本局随机生成器。
- 难度决定地图出怪时使用的怪物池，具体怪物池内容在后续配表阶段确定。
- 使用随机数与难度，确定性构建本局的物资点和怪物分布。
- 开始探索前，一次性生成并保存所有物资点中的物品数量、稀有度和具体物品。
- 使用本局随机数，从地图预设的撤离点中决定一个开放点位。
- 完成开局生成后，敌人 AI、逃跑判定和敌人掉落等运行时随机继续沿用本局随机生成器；已经生成的物资点内容不会改变。
- 进入地图后，在游戏 UI 上显示本局随机数。

## 地图的基本形式

- 原型阶段只制作一张地图。
- 地图类似地牢，由多个互相连接的房间组成。
- 房间分为普通房间（`Normal`）与走廊（`Corridor`）：
  - 走廊在数据结构上同样视为一种房间，用于连接各普通房间；
  - 走廊上不刷新敌人队伍与物资点；
  - 走廊具备独立的矩形包围盒，用于精确定位玩家当前所在区域（为后续迷雾/探索显露系统提供底层支持）。
- 房间结构和连接关系固定，不参与随机生成。
- 整张地图在进入单局时一次性加载，房间只用于划分地图区域与判定归属，不进行分房间流式加载。

## 玩家如何移动

- PC 端通过 WASD 控制队长（领队，出战第 1 位）在瓦片地图中移动。
- 所有出战角色（随从）都会在地图中以蛇形队列跟随队长。
- 移动速度由 Luban 全局表配置（`PlayerSpeed`），保持玩家移动速度略大于敌人的追击速度。
- 地图中的移动、物资搜索以及**敌人接触进战等碰撞判定严格由队长负责**（随从碰触敌人不触发战斗）。

## 玩家如何搜索

### 物资点内容生成

- 不使用统一物资池直接决定物资点内容。
- 每种物资点针对每个难度，分别配置刷新道具数量和各稀有度的刷新权重。
- 进入单局并构建物资点内容时，先随机本次刷新的道具数量。
- 每个道具先根据稀有度权重随机稀有度，再从对应稀有度的道具集合中随机具体道具。
- 以上随机过程使用本局随机数，保证相同随机数与难度能够复现相同结果。
- 物资点内生成道具的搜索顺序固定，暂停和恢复搜索不会改变顺序。

### 搜索与逐件掉落

- 玩家对地图上的物资点长按交互进行搜索。
- 搜索过程中禁止玩家移动。
- 玩家提前松开交互键时，保留当前搜索进度。
- 搜索过程中与敌人碰撞时，立即中断搜索并进入战斗，同时保留当前搜索进度。
- 每件物品根据自身稀有度提供一段搜索耗时。
- 物资点的总搜索时间，等于其中所有物品搜索耗时之和。
- 物品按照搜索顺序逐个出现；第 N 件物品的出现时间，等于前 N 件物品搜索耗时的累计值。
- 每件物品达到对应累计时间后，从物资点掉落到地图上，不需要等整个物资点搜索完成。

搜索时间示例：

| 物品 | 单件搜索耗时 | 累计出现时间 |
| --- | --- | --- |
| 白色物品 | 0.2 秒 | 0.2 秒 |
| 绿色物品 | 0.4 秒 | 0.6 秒 |
| 红色物品 | 1.0 秒 | 1.6 秒 |

- 示例物资点的总搜索时间为 `0.2 + 0.4 + 1.0 = 1.6` 秒。

### 拾取与持久化

- 已经从物资点掉落的物品进入等待拾取状态，不会因停止搜索或进入战斗而消失。
- 玩家靠近掉落在地图上的物品并按下交互键，物品进入背包。
- 物资点内全部物品都已掉落后，该物资点禁止再次交互。
- 玩家离开房间后，未拾取物品、物资点搜索进度和已搜索完成状态继续保留。

## 如何触发遭遇

- 敌人在所属房间内巡逻，巡逻速度与追击速度由 Luban 全局表配置（`PatrolSpeed`、`ChaseSpeed`）。
- 巡逻漫游在房间包围盒内挑选随机目标点，留出充足安全内缩距（Padding >= 1.2m）以避开外墙碰撞体；单段巡逻超时（5 秒）或位移受阻卡死（0.8 秒无有效位移）时自动放弃并重新选点。
- 每个敌人拥有独立的警惕值。
- **圆形 360° 全向视距**：由于 2D 顶视角单贴图缺乏明确的角色朝向视觉反馈，敌人视距统一采用纯欧氏距离圆形判定（不使用面向夹角点积）。
- 玩家位于敌人圆形视距内时，警惕值随时间增加；距离越近，增加速度越快（分段阶梯增长）。
- 首版不实现墙体对敌人视野的遮挡。警惕判定只考虑距离，因此允许隔墙增加警惕值。
- 视野的最大距离、不同距离对应的警惕值增长速度，以及脱离视线后的下降速度，都由敌人的威胁等级（`ThreatLevelConfig`）决定。
- 玩家脱离敌人视线后，警惕值按照该威胁等级配置的固定速度下降。
- **满警惕同房间追击锁定**：警惕值满后，敌人进入追击状态；**只要玩家仍在所属房间内，无视拉开的视距持续保持追逐**。
- 敌人不能追出所属房间。当玩家跨出该房间（进入走廊或其他房间）后，敌人追击状态断开并进入丢失目标（`LostTarget`）倒计时。
- 敌人丢失玩家目标 3 秒后停止追击并返回巡逻。
- **碰撞进战门禁（方案 B）**：所有战斗由**玩家领队（队长，`PartyOrder == 1`）与敌人发生物理碰撞**触发；敌人碰触随从队员（`PartyOrder > 1`）直接忽略，不触发战斗。
- 发生碰撞时，如果敌人警惕值未满，则进入先制战斗，第一轮所有玩家角色优先于所有敌人行动。
- 发生碰撞时，如果敌人警惕值已满，则按普通规则进入战斗。
- 每个地图敌人代表一个预设敌人队伍。
- 附近的其他地图敌人不会加入同一场战斗。

## 战斗结束后

- 战斗胜利后，触发战斗的地图敌人消失，并有概率在地图上掉落部分物品。
- 玩家回到进入战斗前所在的位置。
- 未在战斗中阵亡的玩家角色将当前 HP 和 MP 原样带回探索。
- 只要战斗不是以全员阵亡结束，所有在本场战斗中阵亡的玩家角色都以 1 点 HP 和 1 点 MP 返回探索。
- 战斗中的状态不会带回探索。
- 其他地图敌人的警惕和追击状态保持不变。
- 逃跑结束返回地图后，队伍获得 2 秒保护；保护期间敌人不会增加警惕值、不会追击，也不会触发战斗。
- 保护时间结束时，如果队长仍与敌人发生碰撞，则允许立即再次进入战斗。

## 局内限制或压力

- 单局时间上限为 25 分钟。
- 正常探索、搜索物资和打开背包时，单局计时继续。
- 进入回合制战斗后，单局计时暂停。
- 打开菜单时进入暂停页面，单局计时暂停。
- 局内压力主要来自时间上限，以及敌人的警惕与追击。

## 如何撤离

- 地图中预先标记多个撤离点。
- 每局根据随机数只开放其中一个撤离点。
- 本局开放的撤离点在时限内可以随时使用。
- 单局计时达到 20 分钟时，通过小地图 UI 标记本局开放的撤离点并提醒玩家。
- 玩家面向开放的撤离点进行交互后，立即视为成功撤离。

## 死亡与结算

- 成功撤离时，背包中的全部内容进入局外主仓库。
- 玩家死亡时，只保留保险箱中的内容。
- 达到 25 分钟上限时仍未成功撤离，判定撤离失败，只保留保险箱中的物品。

## 最少需要显示的信息

- 地图中的撤离点标记。
- 游戏 UI 显示本局使用的随机数。
- 单局剩余时间常驻显示。
- 游戏包含小地图 UI；单局计时达到 20 分钟时，在小地图上标记本局开放的撤离点。
- 长按搜索时，在物资点上显示整个物资点的搜索进度条。
- **头顶警惕 UI 显隐与变色**：
  - 每个敌人头顶挂载 Canvas（含背景 `bg` 和进度条 `alert`）；
  - **警惕值为 0 时，整个头顶 UI 彻底隐藏（`SetActive(false)`）**，未警戒时不展示任何空圆环；
  - **警惕值大于 0 时自动激活显现**，使用 Unity `Image.fillAmount` 表示当前警惕值比例；
  - 警惕值满时，图标颜色由白色切换为红色；
  - 警惕值衰减归零后，头顶 UI 重新自动隐藏。

## 原型验收

- [ ] 不同单局中的房间结构和连接关系保持不变。
- [ ] 走廊作为特殊房间支持区域包围盒判定，且不刷新敌人与物资点。
- [ ] 整张地图只加载一次，离开房间不会卸载该房间的状态与物品。
- [ ] 相同随机数与难度生成相同的物资点和怪物分布。
- [ ] 进入地图时一次性生成所有物资点内容；之后的运行时随机不会改变已经生成的物品数量和种类。
- [ ] 物资点能够按照“随机数量、随机稀有度、随机具体道具”的顺序生成内容。
- [ ] 长按搜索物资点时玩家无法移动，物品能够按照累计搜索时间逐个掉落到地图。
- [ ] 主动停止搜索或被战斗打断后，搜索进度和已经掉落的物品都能保留。
- [ ] 物资点搜索完成后禁止再次交互，离开房间后未拾取物品仍然存在。
- [ ] 靠近地图物品并按交互键后，物品能够进入背包。
- [ ] 所有出战角色以蛇形跟随队长，队长负责移动与房间边界判定。
- [ ] 仅队长（领队）与敌人碰撞触发战斗，随从碰触敌人不触发战斗。
- [ ] 敌人在房间内巡逻，具备内缩 Padding、超时与防卡死自恢复。
- [ ] 敌人采用圆形 360° 视距探测，同房间近距离分段增长警惕值。
- [ ] 首版允许敌人隔墙增加警惕值，警惕判定不计算墙体遮挡。
- [ ] 玩家脱离视线后，警惕值能够按照固定速度下降。
- [ ] 敌人警惕值满后能够追击玩家，同房间内持续锁定追逐；跨房离开后 3 秒脱战重置巡逻。
- [ ] 敌人不能追出所属房间。
- [ ] 警惕值未满时发生碰撞进入先制战斗，警惕值满时发生碰撞进入普通战斗。
- [ ] 一个地图敌人只触发自身代表的预设敌人队伍，附近敌人不会加入战斗。
- [ ] 非全员阵亡的战斗结束后，阵亡角色以 1 点 HP 和 1 点 MP 返回探索。
- [ ] 逃跑后的 2 秒内敌人不追击且无法进入战斗；保护结束时仍重叠则可以立即再次战斗。
- [ ] 敌人头顶警惕图标在警惕值为 0 时完全隐藏，大于 0 时显现并按 `fillAmount` 填充，满值变红。
- [ ] 单局剩余时间常驻显示，搜索时物资点显示整体搜索进度条。
- [ ] 随机数能够确定本局开放的撤离点，交互后能够完成撤离。
