# P1-M1 顶级 UI 拆分

2026-10-25 实现；范围仅为 P1-M1，保留原有战备、装备和仓库能力。

## 页面

| 入口 | 顶级 Form / ID | 子组件 |
| --- | --- | --- |
| Expedition | HomeForm / 111 | SquadForm、DeploymentForm |
| Roster | LoadoutForm / 112 | CharacterPreviewForm |
| Warehouse | WarehouseForm / 113 | InventoryForm、ItemDetailsForm |
| Supply（禁用） | ShopForm / 114 | P1-M3 前仅占位 |

所有页面注册在 Default 组，禁止多实例，暂停被覆盖页面。大厅不再嵌套上述功能页。既有局内 CharacterForm 不变。

## 大厅布局修订

根据用户提供的参考图，大厅改为中心偏左的模型展示空间与边缘导航。`LobbyForm/PageContent/ModelDisplayRoot` 预留约 48% 屏宽、68% 内容高度的展示区域，尚未放入模型；下方为装饰性底座与地面透视线。整备、仓库入口在左侧，补给与主要出征入口在右侧，状态与标题置于顶栏。现有按钮引用和事件接线保留。

## 实现约定

- 独立页面全屏布局，保留原子面板和已配置组件引用。
- 统一页头：返回按钮、连接状态、金币待接入占位；返回经池化 UI 事件按 SerialId 路由。金币与交易仍归后续里程碑，未创建假余额。
- 返回关闭当前功能页，UGF 恢复大厅；ESC 不打断输入框编辑。开页期间锁定导航，失败及返回恢复导航。
- 开页/恢复/快照落地刷新；关闭保存脏状态并通知现有网络同步层。复用现有开局事件与 ProcedureMenu 离开时关闭所有 UI 的流程。
- prefab 创建、拆分、生成引用与预览通过本机 mcp-for-unity HTTP 会话完成；源配置由源 xlsx 修改后运行 gen_cli.bat 导出。没有手改生成代码。

## 静态验证

- Editor 内检查五个顶级 prefab 的生成 View / Form / 页头引用：0 个空引用、0 个丢失脚本；Lobby 仅有自身一个 Form。
- Editor 隔离预览场景渲染五页（1920×1080），确认页头与内容布局；静态预览不初始化账号、角色列表或库存。
- 代码复核覆盖开页去重、返回路由、暂停恢复重新绑定、快照刷新取消旧拖拽、开局切场景链路。
- 原有联网 v2 未提交改动保留。本次不修改 Net 服务、结算与 Go 服务端。
