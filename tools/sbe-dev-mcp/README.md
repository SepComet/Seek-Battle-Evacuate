# sbe-dev-mcp

SBE 仓库的本地开发工作流 MCP server（stdio，Go 标准库零依赖）。注册于 `<repo>/.zcode/config.json` 的 `mcp.servers["sbe-dev"]`（该文件被 .gitignore 忽略，属本机配置）。

## 工具

| 工具 | 作用 |
| --- | --- |
| `luban_export` | 等同 `SBE-Design/gen_cli.bat` 完整行为：cs-bin 代码导出 → json+bin 数据导出 → DataTables/*.json LF 归一化 → 报告 git 变更。两个 gen_cli 脚本现都内置 LF 归一化（sh 版必须无条件转换：Git Bash/MSYS2 经自身路径读文件会透明剥 CR，带 grep 检测的守卫会静默漏转 CRLF 文件）。 |
| `server_test` | 在 SBE-Server 跑 `go test -json`，返回通过/失败/跳过计数、失败用例输出、编译错误。 |
| `consistency_check` | 只读预检：Luban 表名四处一致（`__tables__.xlsx` ↔ `Gen/Tb*.cs` ↔ `Tables.cs` 构造参数 ↔ `LubanComponent.TableNames` ↔ DataTables 产物 ↔ Datas 工作簿）、生成文件 `<auto-generated>` 头、asmdef GUID 引用可解析（含 Library/PackageCache 二级解析）。 |
| `deploy` | 一键部署 Docker 栈（`SBE-Server/docker-compose.yml`：MySQL + 游戏服务器）。默认 `up -d --build --force-recreate sbe-server`（日常改码更新路径）并轮询等待服务器监听日志；`service=all` 整栈首次部署。需要 Docker Desktop 运行中；基础镜像（golang:1.27-alpine / alpine:3.21）直连 docker.io 走 IPv6 黑洞，需挂代理拉取一次。 |
| `smoke` | 对容器服务器跑注册/ping/登录冒烟（`cmd/smoke`），默认 `127.0.0.1:7777`。部署后确认服务可用；register 被拒且 code=internal 通常是容器二进制与库 schema 不匹配，需重新 deploy。 |
| `unity_verify` | Unity 客户端验证，按 Editor 状态分流。`mode=check`：只查 `Temp/UnityLockfile`（Editor 是否运行，三态：运行中 / 疑似残留锁 / 未运行）、项目 Unity 版本（`ProjectVersion.txt`）与 Unity.exe 路径（Hub 目录自动解析，可 `unity_path` 覆盖），秒回。`mode=tests`：**一条命令同时得出编译+测试双结论**（`-runTests` 隐含完整编译：先从日志解析编译结论——命中 `error CS` 即失败且测试必然未运行，再从 NUnit XML 解析测试明细；`test_filter` 可过滤；跑前自动扫描测试源码中 `WaitForEndOfFrame` 等 `-nographics` 下会永久挂起的 yield 指令并告警）。`mode=compile`：只想快速查编译时用（`-quit`，热 Library 约 15s~1min）。**残留锁自愈**：lockfile 存在但 tasklist 无 Unity 进程时，判定为 batchmode 退出残留（Unity 退出不删锁是已知行为）并自动清除后继续；仅 lockfile + Unity 进程并存才真正拒绝（Editor 运行中，改走 mcp-for-unity）。任何情况不跑 Play Mode。热 Library 下 tests 全程约 15s~3min（375 例执行仅 1.5s，大头是 domain reload），适合收尾门禁。已知存量失败：fog 用例（EditMode 无 Grid）会红属预期。 |

Unity 编辑器**内**的操作（改场景、改 prefab、Editor 运行中跑测试）不走本 server，走 **mcp-for-unity**（HTTP `http://127.0.0.1:8095`，需 Editor 开启）。Editor **未**运行时的编译检查与 EditMode 测试由本 server 的 `unity_verify` 以 batchmode 完成。

## 构建

`go` 已加入用户环境变量；若某些进程未继承新 PATH，用绝对路径构建：

```bash
cd tools/sbe-dev-mcp
"/c/Program Files/Go/bin/go.exe" build -o bin/sbe-dev-mcp.exe .
```

## 注册（重建 `.zcode/config.json` 时）

```json
{
  "mcp": {
    "servers": {
      "sbe-dev": {
        "command": "D:/UnityProjects/Seek-Battle-Evacuate/tools/sbe-dev-mcp/bin/sbe-dev-mcp.exe",
        "args": [],
        "env": { "SBE_REPO_ROOT": "D:/UnityProjects/Seek-Battle-Evacuate" }
      },
      "mcp-for-unity": {
        "type": "http",
        "url": "http://127.0.0.1:8095"
      }
    }
  }
}
```

`SBE_REPO_ROOT` 也可省略：server 会从 cwd / 可执行文件位置向上找含 `AGENTS.md` + `SBE-Design` 的目录。
